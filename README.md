## PROJETO INTEGRAÇÃO FÍSICA - UC: TESTES PARA BACK-END 3° TI B
Projeto escolar em PHP para comparar medições antes e depois de um biofiltro: pH, turbidez, cloro residual, dureza e temperatura.
O sistema mostra as diferenças e calcula a redução percentual de turbidez e dureza.

## Testes
´php tests/EnsaioFiltroTest.php´
São 18 testes de classificação, cálculos, eficiência, casos felizes, borda e erro.
As classificações são testadas com faixas fictícias, pois a atividade não forneceu referências. O sistema se relaciona à ODS 6 e não determina se a água é potável.
